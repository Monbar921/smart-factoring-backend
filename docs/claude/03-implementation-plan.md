# SMF-33. План реализации по модулям

Принцип: модули последовательно, каждый — законченный и проверяемый кусок. Сначала скелет прогона «насквозь»,
потом наполняем блоки. ML поднимается заглушкой рано, реальные модели — позже, не блокируя backend.

| # | Модуль | Репо | Что делаем | Готово, когда |
|---|---|---|---|---|
| 0 | Контракты и схема | docs, backend | Модель данных (ER), Liquibase основной и `demo`-схем, таблица параметров; OpenAPI backend (прогон, шаги, воронка, детализация, очередь, карточка, решение); OpenAPI сервиса моделей | Схема накатывается, контракты согласованы |
| 1 | Каркас прогона | backend | `run`/`run_step`/журнал, старт (ПР-2), один за раз (ПР-3), асинхронные шаги-заглушки, статусы (ПР-6), история (ЭП-8), API статуса | Через Swagger запускается прогон, шаги проходят, статусы видны |
