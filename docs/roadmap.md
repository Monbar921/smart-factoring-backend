### 1.1а. По итогам воркшопа «Защита данных: от требований закона к техническим решениям» (20.11.2026)

Воркшоп Академии Финтеха (И. Ступников, BI.ZONE) — что эксперты ждут по критерию «Данные, безопасность и комплаенс».
Главная мысль: «цель → граница → проверка»; документ без работающей и проверенной реализации не засчитывается, план
не выдаётся за выполненную проверку. Итог воркшопа — чек-лист перед первым пилотом из шести пунктов: данные,
основание, маршруты, права, завершение, проверка. Ниже — что из этого не закрыто у нас (сверено с кодом 21.11).

Из ответов на вопросы: персональные данные хранятся только в РФ; при утечке через ваш продукт отвечаете вы, при
утечке у хранилища — оно, но репутационный риск остаётся вашим; перед запуском MVP — сканеры кода и приложения
(SAST, DAST, открытые), при бюджете — пентест; с ИИ пользователь не должен работать напрямую — в модель уходят
только строго определённые приложением данные, зарубежные модели — только с обезличенными данными, своя модель
в контуре упрощает контроль; чаще всего утечки — человеческий фактор: слабый пароль администратора, фишинг.

- Подключение нового покупателя (лимит до порога, ручная проверка).

- Отдельное приложение для клиента банка.
