# Экономический эффект и финансовая модель

Как считается ценность Smart Factoring для банка: доход по предложениям, затраты, окупаемость, высвобождаемое время
менеджеров. Расчёт один и тот же в трёх местах:

| Где | Что |
|---|---|
| backend, `GET /runs/{id}/economics` (Р-76) | считает эффект по предложениям выбранного запуска при заданных ставке фондирования и базовом TR |
| экран «Экономический эффект» (`#/economics/{id}`) | показывает его вживую, ставки меняются ползунками |
| финансовая модель `Smart_Factoring_Financial_Model.xlsx` | тот же расчёт формулами по выгрузке предложений запуска, плюс затраты по статьям, денежный поток на 3 года и сверка с API |

## Цепочка расчёта

```
предложения запуска (блок 5: сумма финансирования EAD, срок, EL, TR)
  │  при выбранной ставке фондирования - цена и доход по п. 5.1 заново, EL из запуска
  │  предложение с доходом ниже минимального из-за новой ставки выпадает
  ▼
× TR - шанс, что клиент согласится (базовый TR, ×1,5 за каждый признак п. 5.3)
  ▼
процентный доход − фондирование − ожидаемые потери − опер. расходы = доход банка (по запуску)
  ▼
× оборачиваемость = 365 / средний срок финансирования (взвешенный по EAD) → доход за год
  ▼
÷ клиентов запуска × клиентов масштаба → демо / «ядро» / весь сегмент
  ▼
− сопровождение (постоянная часть + на клиента) = эффект в год
  ▼
окупаемость = внедрение / (эффект / 12), мес.
```

Отдельно, в окупаемость не входит: высвобождаемое время менеджеров = клиенты × проработок в год × (ручная проработка −
время с системой). Время не превращается в деньги само: менеджер тратит его на продажи, поэтому в окупаемость его не
включаем — расчёт консервативный.

### Почему так

- **Доход банка** — это маржа п. 5.1 после фондирования, ожидаемых потерь и операционных расходов, а не выручка: риск
  и стоимость денег уже вычтены.
- **TR** — правило BRD (7%, ×1,5 за признак), а не измерение. На пилоте его заменит модель по решениям менеджеров;
  ползунок показывает, как эффект зависит от этого допущения.
- **Оборачиваемость.** Запуск — снимок открытой дебиторки на дату расчёта. Пока УПД снимка гасятся (в среднем за срок
  финансирования), клиенты отгружают новые, и следующий анализ находит новые предложения. Поэтому годовой доход —
  доход снимка × 365 / средний срок.
- **Масштаб** — среднее на клиента запуска × число клиентов. «Ядро» и сегмент — расчёт команды по RFSD (ГИР БО),
  BRD «Проблема клиента»: компании с выручкой 0,8–2 млрд ₽ и полной отчётностью за 2024–2025 годы (22 641), из них
  с долгой оборачиваемостью дебиторки и низкой ликвидностью одновременно — 5 759.
- **Ставка фондирования** меняет цену для клиента (цена = затраты + маржа), пока цена ниже рыночной (24%). Выше потолка
  растут только расходы банка: доход падает, и предложения, где он ниже минимального (3 000 ₽), выпадают.

## Допущения

Значения по умолчанию — `smart-factoring.economics` в `application.yml` (переопределяются переменными `ECONOMICS_*`)
и лист «Допущения» финансовой модели. Все — оценки команды, уточняются на пилоте.

| Допущение | Значение | Обоснование |
|---|---|---|
| Внедрение | 18,6 млн ₽ | 6,5 ставки (руководитель, 2 backend, frontend, ML, аналитик, 0,5 ИБ) × 6 мес. × 400 тыс. ₽ с начислениями + сервер с GPU для LLM в контуре 3 млн ₽ |
| Сопровождение | 10,8 млн ₽ в год | 2 ставки × 12 мес. × 400 тыс. ₽ + инфраструктура 1,2 млн ₽ |
| На клиента | 600 ₽ в год | вычисления, хранение, тексты LLM |
| Проработок клиента в год | 4 | ежеквартальный пересмотр дебиторки клиента |
| Час менеджера | 1 500 ₽ | с начислениями |
| Часов на ставку | 1 970 | норма при 40-часовой неделе |
| Ручная проработка / с системой | 200 / 20 мин | BRD «Проблема менеджера», Приложение А |

## Ограничения

- Клиенты, УПД и платежи демо синтетические (генератор ML-команды): средние на клиента — порядок величины, не прогноз.
  На пилоте модель пересчитывается на реальных данных банка той же выгрузкой.
- Набор предложений при другой ставке не пересчитывается заново: выпадают только предложения ниже минимального дохода,
  остальные правила п. 5.2 от ставок не зависят. Деление лимита покупателя (п. 5.3) остаётся как в запуске.
- Не учтены: комиссии ВТБ Факторинга сверх цены, кросс-продажи, удержание клиентов, стоимость капитала под риск.

Главный риск эффекта — ставка фондирования: выше ~20% годовых цена упирается в рыночный потолок 24%, и доход банка
быстро падает. Главная неопределённость — TR: эффект ему пропорционален; на пилоте TR заменит модель по фактическим
решениям клиентов.
